# 坚果云第三方应用管理客户端（非官方）

一个用于管理坚果云 WebDAV 第三方应用密码的本地客户端，包含：服务器地址、账号展示、创建新应用密码、查看已创建应用的名称 / 授权日期 / 应用密码、删除应用密码。

## 运行

```bash
cd nutstore-asp-client
python server.py
```

浏览器打开 http://127.0.0.1:8787 即可使用。仅依赖 Python 3 标准库，无需安装任何第三方包。

## 登录方式

### 方式一：Cookie 登录（推荐）

坚果云网页登录强制要求腾讯滑块验证码，程序无法自动通过，因此推荐直接复用浏览器登录态：

1. 在浏览器登录 www.jianguoyun.com
2. 按 F12 → Network（网络）→ 刷新页面 → 点击任意请求 → Request Headers → 复制整行 `Cookie`
3. 粘贴到客户端的 Cookie 输入框

### 方式二：账号密码登录

客户端会尝试直接提交登录表单，但由于验证码限制，大概率失败；失败时请改用 Cookie 登录。

## 功能

| 功能 | 说明 |
| --- | --- |
| 服务器信息 | 展示 WebDAV 服务器地址 `https://dav.jianguoyun.com/dav/`（可一键复制）、当前账号、应用数量 |
| 应用列表 | 展示所有已创建应用的应用名称、授权日期、应用密码（默认打码，可显示/复制） |
| 创建应用密码 | 输入应用名称即可生成，生成后弹窗展示完整密码（可复制） |
| 删除应用密码 | 删除指定应用密码，删除前二次确认 |

## 实现原理

坚果云未公开应用密码管理 API。本客户端使用其移动端网页接口（与官方 Windows/安卓客户端的"第三方应用管理"同源）：

- 列表：`GET /d/mobile_asp` → 从 HTML 中提取 `userAspsStr` JSON
- 创建：`POST /d/ajax/userop/generateAsp`，参数 `asp_name`
- 删除：`POST /d/ajax/userop/revokeAsp`，参数 `asp_name`

所有请求由本地 `server.py` 代理（解决浏览器跨域限制），凭证仅保存在本机内存中，服务关闭即消失，不落盘、不上传。

## 风险提示

- 非官方实现，坚果云接口变更可能导致客户端失效。
- 请勿将 Cookie 提供给不信任的程序；本客户端代码开源可审计。
